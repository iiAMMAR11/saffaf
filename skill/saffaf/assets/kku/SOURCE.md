# PT Bold Heading

The title font the King Khalid University thesis guide names for the thesis title on the title page (model 1) and the
approval page (model 3), size 20. Used only in the thesis profile (`make.py --profile=kku`), for the title alone.
`PT_Bold_Heading.ttf`, version 2.03 («Designed for Microsoft Corp. by Platinum Inc.»), as published, unmodified.
It is a bold design in a single face named Regular, so the title is set in it without added bold. It has no Latin
letters. `scripts/fonts.py` reads its family name from the file itself; without the file the title is set in
Traditional Arabic bold.
