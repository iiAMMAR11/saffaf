# Times New Roman

The Latin font of every document (Latin words, English footnotes, Latin references, the English abstract of a thesis),
and of the few signs the Arabic fonts lack. The PDF engine uses these files, so the PDF shows Times New Roman itself
rather than a look-alike; the Word file names Times New Roman, which Word has on every system.

Version 2.82, from Microsoft's «TrueType core fonts for the Web» (`times32.exe`), unpacked, unmodified and under their
original names, as the licence requires. Their SHA-256 sums match the ones Debian's ttf-mscorefonts-installer checks:
