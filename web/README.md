# موقع صفّاف — النسخة التجريبية

موقع خدمي يصفّ البحث كما تصفّه المهارة، بالمحرّك نفسه (`skill/saffaf/scripts`)، دون حسابات ولا اشتراكات. وهو للتجربة فقط: لا يُنشر للعامة قبل حسم المسائل المذكورة آخر هذا الملف.

## التشغيل

**بـ Docker (الطريقة الموصى بها؛ هي بيئة claude.ai نفسها: Ubuntu 24.04 وLibreOffice ‏24.2.7.2):**

```bash
docker build -f web/Dockerfile -t saffaf-web .      # من جذر المستودع
docker run --rm -p 8000:8000 saffaf-web
```

ثم افتح `http://127.0.0.1:8000`.

**مباشرة على الجهاز:** يلزم Python 3.10 فأحدث، وLibreOffice، وpoppler-utils.

```bash
pip install -r web/requirements.txt
web/run.sh                                           # http://127.0.0.1:8000
```

## المسار

١ أرسل نصّك ← ٢ راجع البنية (عند الحاجة) ← ٣ الإعدادات ← ٤ المعاينة والتنزيل.

| المرحلة | من يقوم بها |
|---|---|
| **الاستقبال** | رفض PDF والصور بالامتداد وبمحتوى الملف، ورفض الصيغ غير المعروفة، وحدّ للحجم قدره ١٥ ميغابايت |
| **التحويل** | `to_md.py` كما هو. ويُرفض النص المنسوخ من PDF بالجملة الجاهزة نفسها، ومعها كلمتان تالفتان من نص المستخدم |
| **البنية** | `structure.py`: قواعد العناوين (المقدمة، المبحث، المطلب…)، وعنوان المقال، وسطر الكاتب، والرأس المدمج. وفي النص الملصوق تُربط الحواشي «(١)» بأسطرها في آخره إذا كان الربط لا يحتمل إلا وجهًا واحدًا، وتصير الأسطر المفصولة بعلامات الجدولة جدولًا |
| **المراجعة** | يرى المستخدم أدوار الأسطر ويصحّحها. والدور لا يغيّر إلا موضع السطر وشكله |
| **الإعدادات** | النوع (مقال، أو بحث بغلاف، أو رسالة علمية)، والغلاف، وفهرس الموضوعات، والرسم العثماني، وفهرس الآيات. وتحت «خيارات أخرى»: الترويسة، والخط، والبسملة المخطوطة، وتحويل الرموز، وترتيب المصادر، واستثناءات دليل الجامعة |
| **الصفّ** | `make.py` كما هو، بخيارات المهارة نفسها |
| **التحقق** | لا يُسلَّم ملف حتى يوجد كل سطر من نص المؤلف في ملف Word حرفًا بحرف (`pipeline.check_output`) |
| **التسليم** | PDF وWord وملف الخطوط، ومعاينة الصفحات، والتنبيهات بالعربية |

## ضمانة النص

١. **قبل الصف:** يُعاد بناء نص المؤلف من الملف الذي يقرؤه المحرّك (`in.md`)، ويُقارن بالمسودة حرفًا بحرف (`structure.verify`). فإن اختلف شيء لم يبدأ الصف. ويُرفض كذلك أي بيان في الغلاف ليس من النص ولا مما أدخله المستخدم.

٢. **بعد الصف:** يجب أن يوجد كل سطر من نص المؤلف في ملف Word الناتج. وإلا حُذف الناتج وظهر للمستخدم أن الخلل في صفّاف لا في نصه.

وما يُستثنى من الفحص هو ما اختاره المستخدم صراحةً فقط: الآيات بالرسم العثماني، والبسملة المخطوطة.

## عزل المهام

- **لكل مستند مجلد خاص** فيه: ملفاته، ومجلده المؤقت (`TMPDIR`)، ومجلد منزله (`HOME`)، وملفا إعدادات LibreOffice الخاصان به.
- **الإيقاف عند المهلة يطال المهمة وحدها:** تتوقف المهمة وكل عملية بدأتها، ولا تتأثر مستندات المستخدمين الآخرين. وكان المحرّك يوقف كل عمليات LibreOffice في الخادم؛ وصار الآن يوقف عملياته هو فقط.
- **الحذف:** تُحذف ملفات المهمة كلها بعد ساعة، أو حين يضغط المستخدم «احذف ملفاتي الآن».

**الإعدادات:**

| المتغيّر | الافتراضي | معناه |
|---|---|---|
| `SAFFAF_WORKERS` | ٢ | عدد المستندات التي تُصفّ في وقت واحد |
| `SAFFAF_JOB_TIMEOUT` | ٩٠٠ ث | أطول مدة للصف الواحد |
| `SAFFAF_JOB_TTL` | ٣٦٠٠ ث | مدة بقاء الملفات قبل حذفها |
| `SAFFAF_JOBS_DIR` | — | مكان مجلدات المهام |
| `SAFFAF_FONTS_INSTALLED=1` | — | الخطوط مثبّتة في النظام مرة واحدة (كما في الحاوية) |
| `SAFFAF_ENABLE_MS_FONTS=0` | — | يعطّل نمط الرسائل وخط Traditional Arabic (انظر مسائل الترخيص) |

## الاختبارات

```bash
python3 tests/run_tests.py                            # اختبارات المحرّك (٢٠٨)
cd web && python3 -m unittest tests.test_structure tests.test_assist tests.test_service tests.test_concurrency
```

| الملف | ما يختبره |
|---|---|
| `test_structure` | قواعد البنية؛ وربط حواشي النص الملصوق وتركها حين يحتمل الربط أكثر من وجه؛ والجداول؛ و٣٠٠ تجربة عشوائية لأدوار الأسطر لا يتغيّر في أيٍّ منها النص؛ وكشف أي تلاعب |
| `test_service` | كل صيغة مقبولة؛ وكل حالة رفض؛ والمسار كاملًا عبر الواجهة البرمجية؛ وبقاء النص حرفًا بحرف في ملف Word؛ وإيقاف التسليم إذا تغيّر حرف؛ وحذف الملفات |
| `test_concurrency` | مستندان متزامنان يخرجان مطابقين لصفّهما متتابعين؛ وإيقاف مهمة لا يمسّ غيرها؛ وبقاء الملفات المؤقتة داخل مجلد المهمة |
| `test_assist` | مدقّقات أجوبة المساعد، بأجوبة مكتوبة يدويًا دون أي اتصال |

ولتشغيلها يلزم `pip install -r web/requirements-test.txt`.

## المساعد الذكي (جاهز وغير مفعّل)

في `web/assist/`، وهو منفصل عن المحرّك. لا يكتب النموذج نص المؤلف أبدًا، بل يجيب بأرقام الفقرات ومواضع الحروف وتسمياتها فقط. ثم يتحقق `validate.py` من كل جواب قبل أن يُطبَّق:
- يجب أن تطابق كل علامة كلماتِ المؤلف نفسها.
- لا يُقبل بيانٌ لمصدر إلا إذا وُجد في نص المؤلف أو أدخله المستخدم.
- ويجب أن يعود النص بعد نزع العلامات كما كان.

| المهمة | ما يقدّمه |
|---|---|
| `structure` | أدوار الأسطر حين لا تكفي القواعد |
| `notes` | ربط حواشي النص الملصوق حين يحتمل الربط أكثر من وجه (مثل حواشٍ يبدأ ترقيمها من جديد في كل صفحة) |
| `marks` | علامات الفهارس التسعة |
| `sources` | ملف المصادر ومواضع الإحالة لأنظمة الإحالة الخمسة |

**ما يلزم لتفعيله:**
١. قرار المالك، وحساب في Anthropic API بمفتاح وفوترة.
٢. إشعار المستخدم وموافقته قبل إرسال نصه.
٣. `pip install anthropic`، ثم `SAFFAF_ASSIST=anthropic` و`ANTHROPIC_API_KEY`، و`SAFFAF_ASSIST_MODEL` اختياريًا (الافتراضي `claude-opus-5-5`).
٤. ربطه بالواجهة: شاشة مراجعة للمداخل والمصادر، ونموذج للبيانات الناقصة. **لم يُبنَ بعد.**
٥. تقسيم الرسائل الطويلة على أكثر من طلب.
٦. قياس الدقة والتكلفة على عيّنة من أبحاث حقيقية قبل الإطلاق.

**التكلفة التقديرية:** هذه أرقام تقديرية لا قياس. الأسعار من جدول Anthropic (أكتوبر ٢٠٢٦، لكل مليون رمز، مدخلات/مخرجات):
- Opus 5.5: ‏٤/٢٠ دولارًا.
- Sonnet 5.5: ‏٢/١٠ دولارات.
- Haiku 5.5: ‏٠٫١٠/٠٫٥٠ دولار.

**الافتراض:** الكلمة العربية بين ٢٫٥ و٤ رموز، ولم يُقَس هذا. يُقاس بـ `count_tokens` قبل التفعيل.

| المستند | المهام | Opus 5.5 | Sonnet 5.5 | Haiku 5.5 |
|---|---|---|---|---|
| بحث من ٨٠٠٠ كلمة | البنية وحدها | ٠٫١٢–٠٫٢١$ | ٠٫٠٦–٠٫١٠$ | أقل من ٠٫٠١$ |
| بحث من ٨٠٠٠ كلمة | المهام الأربع | ٠٫٧–١٫٣$ | ٠٫٣٥–٠٫٦٥$ | نحو ٠٫٠٢–٠٫٠٣$ |
| رسالة من ٦٠٠٠٠ كلمة | المهام الأربع | ٥–١٠$ | ٢٫٦–٥$ | نحو ٠٫٣–٠٫٦$ |

- **أصل الأرقام:** كل مهمة تقرأ النص كله (أو حواشيه وحدها في مهمة المصادر). والمخرجات تسميات قصيرة يُضاف إليها تفكير النموذج، وهو يُحسب ضمن المخرجات.
- **ما يخفّضها:** تخزين النص مؤقتًا بين المهام (prompt caching).
- **جودة Haiku في هذه المهام لم تُختبر.**

## مسائل الترخيص (موثّقة وغير محسومة)

لم يُحذف خط، ولم يُستبدل، ولم يُعدَّل.

| الخط (`skill/saffaf/assets/…`) | التشغيل على الخادم | التضمين في PDF وWord | توزيع ملف الخط (ملف الخطوط المضغوط) |
|---|---|---|---|
| `fonts/_LotusLotfi-*.ttf` | مفتوح: بيانات الملف (السجلات 0 و7 و13) تنسب الملكية إلى Heidelberger/Linotype وتشترط إذنها، و`CLAUDE.md` يقول إنه منشور مجانًا بإذن صاحبه. ولا يوجد في المستودع مصدر لذلك ولا نص إذن | قيمة fsType ‏4 تسمح بالتضمين للعرض والطباعة. وحق الاستعمال نفسه مفتوح | مفتوح |
| `quran/UthmanicHafs_V22.ttf` | مسموح بنص رخصته المضمّنة في الخط (السجل 13) | مسموح | مسموح مجانًا. ومفتوح: أثر الخدمة المدفوعة، لأن الرخصة تمنع بيع الخط |
| `symbols/NotoNaskhArabic-Regular.ttf` | رخصة OFL ‏1.1 (`symbols/OFL.txt`) | مسموح | مسموح، ويُرفق ملف الرخصة |
| `times/*.TTF` | مفتوح للخدمة المستضافة: `times/Licen.TXT` يسمح بالاستعمال والتوزيع دون ربح | مسموح، والرخصة تذكر التضمين | لا يُوزَّع |
| `traditional/*.ttf` و`kku/PT_Bold_Heading.ttf` | صفحة Microsoft تحيل رخصة «server installations» إلى Monotype | `tradbdo.ttf` قيمة fsType فيه ٢ (تضمين ممنوع)، ومع ذلك يضمّنه LibreOffice | لم يوجد ما يسمح به |

وخيار `SAFFAF_ENABLE_MS_FONTS=0` يعطّل الخيارين المعتمدين على خطوط Microsoft عند الحاجة، دون حذف أي ملف.
